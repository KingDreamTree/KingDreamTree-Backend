## 1. 세그멘테이션 (A 주도, ~10분)

긴팔 사진 업로드 → 포즈 게이트 → 세그 → DB.

- [ ] **라벨명 정합** — `verify_segmap.py` 실행: 부위별 픽셀 수가
      `segmentation.json`과 일치하는지. **순서 재배열이면 여기서 카운트가 어긋난다**
- [ ] **라벨 순서 눈 검증** — 오버레이 색칠 결과를 눈으로:
      몸통이 몸통 색인지, **좌우가 안 뒤집혔는지** (좌우를 비슷한 색 계열로
      설계한 이유가 이 순간이다 — 대칭으로 뒤집혀 보이면 반전 규칙이 깨진 것)
- [ ] **bbox 좌표계** — 오버레이가 몸에 정확히 붙는지만 눈으로
      (코드 정합은 사전 확인 완료 — 맵 기준·축별 배율·실PNG 크기 사용)

### ⭐ 옷 병합 — 오늘의 핵심 (A의 최대 우려)

- [ ] 병합 **전이면 TOO_SMALL이었을** 상완이 `is_valid=true`로 살아나는지
- [ ] `clothing_pixel_count`가 **0이 아닌 값**으로 차는지 (팔 부위)
- [ ] 옷 안 가린 부위(예: 손목 아래·종아리)는 `0`, 구버전 행 없음 → `NULL` 없어야 정상
- [ ] `retake_recommended` — 긴팔인데도 `valid_comparable ≥ 3`으로 false가 나오는지
      (병합이 제대로면 재촬영 유도가 안 떠야 한다)

**실패 시**: 상완이 여전히 TOO_SMALL → 병합이 is_valid 판정 *이후*에 돌았을
가능성부터 확인 (순서가 생명 — handoff §1).
