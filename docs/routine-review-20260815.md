## 1. 좌우 이중 가산 — 08-14 판단을 되돌린다

08-14 에는 "운동은 좌우를 함께 하니 근육군 예산 하나로 묶어야 한다"고 보고
이중 가산을 막았다. **두 개의 다른 문제를 하나로 뭉갠 것이었다.**

```
양쪽 다 약함  = 그 근육군의 절대 볼륨 부족  → 볼륨을 올린다
한쪽만 약함   = 좌우 불균형                → 볼륨이 아니라 단측 운동으로 교정한다
```

처방이 다르니 예산도 달라야 한다. 양팔이 다 약한 사람과 왼팔만 약한 사람에게
같은 볼륨을 주면 **전자는 부족하고 후자는 불균형이 안 고쳐진다.**

- 근거 — 단측 훈련이 비대칭 교정에 효과적이고 양측 훈련은 그렇지 않다
  (Front Physiol 2023 메타분석). 비대칭 10~15% 초과 시 부상 위험 상승.
- 구현 — `demand` 를 세어 근육군 예산에 곱한다. 배수 상한 `BOOST_MULTIPLIER_CAP = 2`
  (상완·전완이 같은 근육군을 공유해도 3배가 되지 않게).

실측:

| 일수 | 한쪽만 | 양쪽 다 |
|---|---|---|
| 4일 | 이두 3→4, 삼두 3→4 | 이두 3→**5**, 삼두 3→**5** |
| 5일 | 이두 6→8 | 이두 6→**10** |
| 6일 | 이두 6→8, 삼두 6→8 | 이두 6→**10**, 삼두 6→**10** |

6일 양쪽이 정확히 **주 10세트** — Schoenfeld 2017 의 "10세트 초과에서 비대가
더 크다" 밴드 하단이다. 우연이 아니라 `WEEKLY_BOOST_CAP_PER_GROUP=4 × 2` 가
기본 6세트 위에 얹힌 결과다.

> ⚠️ **한계** — 3~4일에서는 예산이 남아도 `slot_sets_cap`(고립 5)이 먼저 막아
> 5세트에서 멈춘다. 슬롯을 새로 만들면 더 넣을 수 있지만, 그건 진단이 Day 의
> **구성**을 바꾸는 것이라 D10 원칙에 어긋나고 세션도 길어진다. 세션 길이를
> 택했다.

### 1-1. 불균형 쪽은 볼륨이 아니라 **순서**로 교정한다 (08-15 추가)

위 표가 "약한 쪽에 볼륨을 더 준다"로 읽힐 수 있어 명시한다. **좌우에 다른
볼륨을 주는 경로는 코드에 없다.** 슬롯은 근육군 단위이고 단측 운동도 양쪽
같은 세트 수로 수행한다. `sets_left` / `sets_right` 같은 필드는 존재하지 않고,
검증에서 그 부재를 감시한다.

한쪽만 약할 때 실제로 조절하는 건 두 가지다:

```
① 단측 운동    양측 운동에서는 강한 쪽이 약한 쪽을 끌고 가버려서(bilateral
              compensation) 세트를 늘려도 격차가 안 좁혀진다
② 약한 쪽 먼저  피로가 없을 때 질 좋은 세트를 약한 쪽이 먼저 가져간다.
              강한 쪽은 약한 쪽이 해낸 횟수까지만 — 안 그러면 격차가 유지된다
```

②가 08-15 이전에 **빠져 있었다.** `single_side: true` 태그로 단측 운동을
고르기만 하고, 어느 쪽부터 할지는 아무 데도 없었다. 진단이 `Left_Upper_Arm`
처럼 방향을 담고 오는데 `_collect_candidates` 에서 근육군으로 접히며 버려졌다.
이제 `slot["weak_side"]` 로 살아 내려와 운동 note 에 붙는다.

> ⚠️ **단측 운동이 실제로 뽑혔을 때만** 안내한다. 후보에 단측이 없어 양측
> 운동이 선택될 수 있는데, 그때 "왼쪽부터"는 수행할 수 없는 지시다.

> ⚠️ 좌우가 **둘 다** 약하면 `weak_side` 를 비운다 — 그 경우엔 "약한 쪽"이라는
> 게 없고, 처방도 불균형 교정이 아니라 볼륨 증가(§1)다.

볼륨 차등을 하지 않는 이유가 하나 더 있다. 우리 진단은 사진 기반이고 좌우
판정의 신뢰도가 그렇게 높지 않다. **순서를 바꾸는 처방은 틀려도 손해가 없지만,
볼륨을 좌우로 갈라 주는 처방은 틀리면 없던 불균형을 만든다.**

## 2. CUT 모드 — "맨몸운동으로 교체"는 근거상 반대다

요청은 "유산소랑 전신 맨몸운동 같은 걸로 더 살빼는 모드"였다.
**목표는 맞는데 수단이 정확히 반대다.**

감량기에 근손실을 막는 것은 저항운동 **강도** 자체다. 열량 제한 중인 비만
고령자에서 저항운동이 제지방 손실의 **93.5% 를 방지**했다(PMC5946208).
무게를 빼면 그 보호 효과가 같이 빠진다 — 살은 빠지지만 근육이 같이 빠진다.

근거가 있는 수단은 **서킷화(밀도 ↑)** 다:

- Resistance Circuit-Based Training 메타분석(PMC8145598) — 서킷은 전통 방식과
  근력·제지방에서 **동등**하면서 심폐·대사 반응이 더 크고 지방 감소에 유리.
- 고강도 서킷 vs 전통 비교(PMID 40323711) — 시간 대비 효율 우위.
- 열량 제한 중 **중강도가 고강도보다 제지방 보존에 낫다**(네트워크 메타분석
  PMC12158682) → 반복수를 12~15 로 올려 중강도 구간에 맞춘다.

### 구현

| 항목 | BALANCE | CUT |
|---|---|---|
| 세트 수 | 그대로 | **그대로** (볼륨 안 깎음) |
| 휴식 (복합) | 90초 | **60초** |
| 휴식 (고립) | 60초 | **45초** |
| 반복 | 10~15 | **12 이상** |
| 유산소 | 없음 | 근력일마다 15~25분 |

무게는 RIR 자가조절이 알아서 낮춘다 — 휴식이 짧아지면 같은 RIR 을 맞추려
사용자가 스스로 무게를 내린다. **우리가 무게를 지정하지 않는 설계가 여기서
이득을 본다.**

유산소 분(分)은 일수에 반비례(1\~2일 25분 / 3\~4일 20분 / 5일+ 15분)해서
주간 총량이 크게 어긋나지 않게 했다. ACSM Donnelly 2009 의 주 150분은 루틴만으로
채우지 않고 `CUT_NOTICE` 의 일상 걷기 안내가 나머지를 담당한다.

## 3. 체지방률별 골격 차등 — 골격은 그대로, 종목만 가른다

"체지방률에 따라 골격 설계를 다르게 할 것인가"를 검토했다. **아니다.**

감량기 제지방 보존의 핵심 변수는 **근육군당 주간 빈도**(2회 이상)인데,
현재 골격이 이미 만족한다:

```
3일 이상 → 주요 근육군 주 2회
1~2일   → 주 1회 (일수 자체의 한계. 스플릿을 바꿔도 못 늘린다)
```

CUT 전용 스플릿을 새로 만들 이유가 없다. 대신 체지방률이 실제로 바꿔야 하는
것은 **관절 부하**다:

- 무릎 관절 반력 — 걷기 체중 ~3배, 달리기 ~8배. 체중이 무거울수록 같은 동작의
  절대 부하가 커진다.
- 비만은 무릎 골관절염의 독립 위험인자. ACSM 도 비만 대상자에게 저충격·비체중
  부하 유산소를 권고한다.

→ CUT(=체지방률 컷오프 초과)이면 **저충격 필터**를 켠다.

| | 근력 | 유산소 |
|---|---|---|
| 저충격 | **우선순위** (슬롯이 빌 수 있어 필터 아님) | **필터** (후보 8개 남아 안전) |

CUT 유산소 후보: 일립티컬 · 인클라인 워킹 · 트레드밀 워킹 · 머신 스테퍼 ·
어썰트 바이크 · 스테이셔너리 바이크 · 얼터네이트 펀칭
(제외: 트레드밀 런 · 점프 로프 · 버피 · 점핑잭 · 워킹 하이니즈 런지)

> ⚠️ 실측에서 잡은 오탐 — "Assault Bike **Run**" 이 `run` 에 걸려 빠졌다.
> 발이 페달에 붙어 있어 충격이 0 인데 하필 저충격 유산소의 대표 종목이다.
> **충격은 동작 이름이 아니라 지지 방식이 정한다** → `LOW_IMPACT_MODALITIES`
> (자전거·일립티컬·스테퍼·로잉)가 이름 판정을 이긴다.

## 4. 진단 가중 볼륨 — 유지

기본 볼륨은 근육군당 주 3~8세트(중앙값 6). Schoenfeld 2017 의 "10세트 초과"
밴드보다 낮지만 **대상이 초보자**라 타당하다:

- ACSM 2009(PMID 19204579) 초보자 권고 — 주 2~3회, 1~3세트, 8~12회.
- 미훈련자의 용량-반응 곡선은 훈련자보다 훨씬 평평하다. 낮은 볼륨에서도 얻고,
  높은 볼륨은 부상·이탈 위험만 올린다.
- 삼두·이두의 직접 볼륨(주 3세트)이 낮아 보이지만 프레스·로우에서 간접 볼륨이
  들어온다. 직접+간접으로 보면 충분하다.

**약점 부위만 10세트 밴드로 올린다** — 이게 진단 가중의 존재 이유다.
전신을 10세트로 올리면 초보자에게 과하고, 약점만 올리면 근거 안에 있다.

## 5. 초보자 후보 필터

`BEGINNER_UNSAFE_TERMS` 는 유지(풀업·플라이오·고난도 체조 제외).
여기에 **직교하는 축**으로 `HIGH_IMPACT_TERMS` 를 추가했다.

목적이 다르다:

```
BEGINNER_UNSAFE  = "초보가 못 한다"        → 항상 적용
HIGH_IMPACT      = "체중이 무거우면 관절이 못 버틴다" → CUT 일 때만
```

⚠️ 유산소는 `is_beginner_safe` 가 **항상 통과**시키므로(점핑잭·버피는 초보
유산소의 기본 동작) 유산소 쪽 충격 판정은 `HIGH_IMPACT_TERMS` 가 단독 책임진다.
두 목록이 겹쳐 보여도 합칠 수 없는 이유다.
