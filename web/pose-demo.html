자세 판정 체험

웹캠으로 web/pose-score.js 를 실제로 돌려봅니다. 판정 기준은 서버에서 받아옵니다.

준비 중…
카메라를 켜주세요
자세 (P)–
팔다리·몸통이 가리키는 방향의 일치도
거리 (F)–
몸통 길이 비율. 유도선 미달은 안내만, 거부선 미달만 막힘
몸통 방향 (R) (관찰용)–
어깨폭 ÷ 몸통길이 의 차이. 0이면 레퍼런스와 같은 방향. 판정에는 쓰지 않습니다 — 잡음이 많아 2026-08-14 에 관문에서 뺐고, 데이터만 쌓는 중
–
OKS (관찰용)–
COCO 기준. 관절별 사람끼리 어긋나는 정도(σ)로 나눈 유사도. 판정에는 쓰지 않습니다 — P 와 나란히 보며 비교하는 중

촬영된 사진

이걸 해보세요 — 산식이 무엇에 반응하는지 바로 보입니다

  • 옆으로 걸어보세요 → 자세 점수가 안 변합니다. 방향만 보기 때문입니다 (좌표를 비교했다면 여기서 떨어집니다)
  • 뒤로 물러났다 앞으로 → 자세는 그대로, 거리(F)만 움직입니다
  • 한쪽 팔만 들어보세요 → 그 관절 막대만 길어지고 점수가 조금 깎입니다
  • 팔을 크게 휘둘러 70°를 넘겨보세요 → 나머지가 다 맞아도 0점이 됩니다
  • 팔을 카메라 쪽으로 뻗어보세요 → 그 관절이 계산에서 빠집니다 (투영 각도가 잡음이라)
  • 몸을 옆으로 돌려보세요 → 각도는 거의 그대로인데 몸통 방향(R)만 치솟습니다 — 지금은 관찰용이라 막지 않습니다
  • 자세를 맞추고 가만히 → 아래 초록 막대가 차오르고 자동 촬영됩니다

여는 방법

python scripts/run_pose_demo.py — API 서버까지 같이 띄우고 브라우저를 엽니다.
